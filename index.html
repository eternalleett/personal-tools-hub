Everyday file and data tools. One place.

Prepare documents, convert images, generate labels and QR codes, or organize contacts directly from your browser. JL Toolkit is designed for laptop and mobile workflows, with consistent navigation and focused workspaces.

Flexible documents

Merge, reorder, rotate and annotate PDF pages using a visual workspace.

Fast data workflows

Convert images, generate codes in bulk, and edit CSV contacts before exporting vCards.

Reusable designs

Build label layouts with draggable elements, editable templates and DPI previews.

How it works

Select a tool from Quick Launch, import your files, preview the results, and export the finished output. Most processing is performed locally in your browser. Some features use external JavaScript libraries and need network access when first loaded.

Built to expand

Each utility has its own module and an independent web address, while sharing the JL Toolkit navigation and visual theme. New functions can be added without disrupting the existing tools.
